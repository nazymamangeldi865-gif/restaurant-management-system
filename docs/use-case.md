# Use Case

## UC-01. Жүйеге кіру

Actor: Клиент

Мақсаты: Пайдаланушының жүйеге кіруі.

Негізгі сценарий:

1. Клиент жүйені ашады.
2. Email енгізеді.
3. Құпия сөзін енгізеді.
4. «Кіру» батырмасын басады.
5. Жүйе мәліметтерді тексереді.
6. Клиенттің жеке парақшасы ашылады.

Нәтиже: Клиент жүйеге кіреді.


## UC-02. Мейрамхананы іздеу

Actor: Клиент

Негізгі сценарий:

1. Клиент іздеу бөліміне кіреді.
2. Мейрамхана атауын енгізеді.
3. Қажетті сүзгілерді таңдайды.
4. Жүйе сәйкес мейрамханаларды көрсетеді.

Нәтиже: Клиент қажетті мейрамхананы табады.


## UC-03. Үстелді онлайн броньдау

Actor: Клиент

Негізгі сценарий:

1. Клиент мейрамхананы таңдайды.
2. Күн мен уақытты енгізеді.
3. Жүйе бос үстелдерді тексереді.
4. Бос үстелдер клиентке көрсетіледі.
5. Клиент қажетті үстелді таңдайды.
6. Клиент броньды растайды.
7. Жүйе броньды деректер базасына сақтайды.
8. Клиентке хабарлама жібереді.

Нәтиже: Үстел сәтті броньдалады.
